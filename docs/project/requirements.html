REQ-001Wi-Fi SoftAP with internal DHCP
Broadcast customizable SoftAP (e.g. NomadLink-XXXX), run internal DHCP server issuing 192.168.4.x addresses, and provide an admin page reachable on the local network. DEVIATION FROM SPEC (recorded per ADR-002, not silently absorbed): the spec asks for a captive-portal redirect, which this firmware cannot produce. lwIP's DNS server is compiled out of the Arduino core, so DHCP clients are handed public resolvers and an OS connectivity probe reaches the real internet with no interception point.
