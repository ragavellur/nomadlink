Honest Status

Hardware capabilities are substantially proven but the product is not started. Three verified capabilities (GNSS, cellular LBS, 4G data) came out of hardware probing, not from the PRD. The PRD contains factual errors about this hardware that must be corrected. Three blocking experiments determine whether the headline features (NAT router, voice, speech) are feasible at all.
