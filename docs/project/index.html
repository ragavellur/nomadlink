Firmware Installer

NomadLink One

Flash the ESP32-S3 router firmware directly from the browser. No command line or Python installation required.

Built from the vendored esp32_nat_router 2.4.17 source in this repository. On top of the base this image adds an explicit uplink selector (WiFi vs A7670E 4G over UART) with a /modem web page, an A7670E PPP driver (components/modem_4g) and RGB status signalling (docs/product/led-signals.md). AP SSID still broadcasts NomadLink; mDNS hostname nomadlink.local. GNSS, camera and SD are not yet in this image.
Source: manifest_nomadlink_esp32s3.json · Version 0.2.0-4g.1 · Upstream base 2.4.17
Recommended: Chrome, Edge or Opera. Close all other serial monitors first. Browser flashing writes bootloader, partition table, otadata and app.

Honest Status

Hardware capabilities are substantially proven and the product has now started to build on them. The decisive gap that was open at the last update is closed: PPP over UART now negotiates end to end on the Airtel SIM, giving the ESP32 a real IP interface (100.76.140.112, gw 10.64.64.64). That was the single precondition gating the NAT router. What is still unproven is product behaviour, not hardware: end-to-end MQTT publish, any forwarding/NAT, and any web portal.
